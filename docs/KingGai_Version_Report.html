3. Free Tier Limitations

⚠️ Important: The current setup costs $0/month but has real constraints that will become problems as traffic grows.

Current Free Tier Constraints

ServiceFree Tier LimitWhat Happens When Exceeded
Render (Backend)750 hours/month, sleeps after 15 min idleFirst request after sleep takes 30-50 seconds to respond. Users think the site is broken.
MongoDB Atlas512 MB storage, shared CPUDatabase becomes full. New posts can't be saved. Queries slow down.
Vercel (Frontend)100 GB bandwidth/monthSite goes offline until next billing cycle.
Render (Backend)512 MB RAMServer crashes under heavy concurrent load.

When Will You Hit These Limits?

Rough estimates:
  • ~1,000 posts → MongoDB starts getting sluggish without indexes
  • ~50 concurrent users → Render free tier may struggle with response times
  • ~10,000 monthly visitors → You're fine on bandwidth but cold starts become annoying
  • ~5,000 posts with replies → Approaching 512 MB storage limit

4. Scaling Roadmap — When Traffic Grows

Phase 1: Low Traffic (0–500 monthly users) — FREE

Where you are now. No changes needed.

  • Current free stack handles this comfortably
  • Cold starts are tolerable with small user base
  • Manual admin approval is manageable

Phase 2: Growing (500–5,000 monthly users) — ~$7–14/month

5. Recommended Next Steps (Priority Order)

If you do nothing else, do these 5 things when you're ready to grow:
  1. Buy a custom domain (~$12/year) — looks professional, builds brand trust
  2. Upgrade Render to paid ($7/mo) — eliminates cold start delays
  3. Add search functionality — users need to find content
  4. Add image uploads via Cloudinary — visual content drives engagement
  5. Add Google login — lowers signup friction dramatically
